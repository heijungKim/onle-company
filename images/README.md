# 이미지 폴더

아래 파일명으로 이미지를 넣으면 사이트에 자동으로 표시됩니다.
파일이 없으면 해당 자리는 점선 자리표시자로 보입니다.

| 파일명 | 위치 | 권장 비율 · 크기 | 내용 |
|---|---|---|---|
| `hero.jpg` | 첫 화면 전체 배경(통이미지) | 16:9 · 2000×1125 이상 (2400×1350 권장) | 해질 무렵 거리. 왼쪽 절반에 글자가 얹히므로 주요 피사체는 오른쪽에 |
| `morning.jpg` | 회사 소개 왼쪽 | 16:10 · 1200×750 이상 | 낯선 도시의 아침 |
| `evening.jpg` | 회사 소개 오른쪽 | 16:10 · 1200×750 이상 | 저녁의 푸드트럭 |
| `service-odigaa.jpg` | 서비스 카드 · 오늘 어디가 | 16:11 · 1200×825 이상 | 오늘 어디가 앱 화면 |
| `service-wasseoyo.jpg` | 서비스 카드 · 오늘 왔어요 | 16:11 · 1200×825 이상 | 오늘 왔어요 앱 화면 |
| `contact.jpg` | 문의 섹션 왼쪽 | 4:3 · 1040×780 이상 | 팀·공간·분위기 사진 |
| `og.jpg` | 카카오톡·SNS 공유 미리보기 | 1200×630 (고정) | 자동 생성됨. 바꾸려면 같은 크기로 교체 |
| `favicon.png` | 브라우저 탭 아이콘 | 정사각형 · 512×512 PNG (배경 투명 가능) | 심볼만, 글자는 작게 보이므로 넣지 않는 편이 좋음 |
| `logo.png` | 헤더 로고 (밝은 배경) | 높이 30px로 표시 · 세로 120px 이상, 가로형 PNG(투명 배경) | 없으면 "오늘 ONLE" 글자가 대신 표시 |
| `logo-white.png` | 푸터 로고 (어두운 배경) | 높이 28px로 표시 · 세로 112px 이상, 흰색 버전 PNG(투명 배경) | 없으면 "오늘" 글자가 대신 표시 |

- JPG 권장, 파일당 500KB 이하로 압축하면 로딩이 빠릅니다. (PNG·WebP를 쓰려면 `index.html`의 해당 `src` 확장자만 바꾸면 됩니다)
- 이미지는 영역에 꽉 차게 잘려서(`object-fit: cover`) 표시되므로 비율이 조금 달라도 괜찮습니다.
- 파일을 넣은 뒤 `git add images && git commit && git push` 하면 배포됩니다.
