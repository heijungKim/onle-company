# 매뉴얼 이미지

앱 화면 스크린샷을 아래 파일명으로 이 폴더에 넣으면 매뉴얼에 자동 표시됩니다 (없으면 빈 기기 틀만 보임).
스크린샷을 바꾼 뒤에는 PDF를 다시 생성해야 합니다 (Edge 헤드리스, HANDOFF 참고).
